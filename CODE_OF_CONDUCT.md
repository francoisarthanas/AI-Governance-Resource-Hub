# Code of conduct

Participation should be professional, evidence-led, and respectful. Debate claims and implementation tradeoffs, not people. Harassment, discrimination, threats, doxxing, spam, undisclosed promotion, and submission of confidential information are not acceptable.

Report conduct concerns privately to the repository owner through the contact method on the owner's GitHub profile. Maintainers may edit, reject, lock, or remove contributions and participation that undermine a safe, useful community.
